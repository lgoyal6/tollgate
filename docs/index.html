A multi-tenant API gateway for shared LLM keys. This page runs the gateway's real admission-control code, the same token bucket and sliding window the Redis Lua scripts implement, on a virtual clock. It exists to prove one claim: rate limiting per replica is quietly wrong, and a shared store is what makes a limit a limit.

the experiment

One tenant, one policy, N gateway replicas behind a round-robin load balancer. Left gateway: each replica counts on its own. Right gateway: every replica checks one shared store before admitting.

admitted requests per second

per-replica counters one shared store

The dashed line is the policy. Everything a curve admits above it is quota the tenant never bought: on a shared LLM key, that's someone's real money.

run it: the simulation uses the shipped limiter code, not a model of it.

The production gateway holds a shared 300 req/s ceiling exact across 3 Kubernetes replicas by making check-and-decrement atomic in Redis Lua, and sustains 2,000 req/s with zero errors at p99 46ms under load, with per-upstream circuit breakers and jittered-backoff retries.
